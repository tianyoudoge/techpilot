# 应用形态验收

验收日期：2026-10-08。验收对象为公开客户端，服务端只提供资产接口。

## 页面与路由

拍题首页、讲题记录、看懂题目、家长学习、讲给孩子、练习、结果和无效地址页都由同一个 Vue 应用与 `App.vue` 外壳呈现。切换阶段、应用导航和浏览器返回不会重新加载文档。H5 使用 history 路由；Tauri 使用 hash 路由，业务组件共用。

模型设置是应用内弹窗。管理员、片段目录和数据库调试页默认不注册、不进入正式构建；维护时显式设置 `VITE_INTERNAL_TOOLS=1` 才启用。这些工具仍使用同一个应用外壳。

## 本轮修正

- 首页通过 KeepAlive 保留本次打开应用期间的选图和裁剪草稿；切换到记录页后返回不会重置旋转结果。成功保存题目后清空草稿。草稿不承诺在应用被系统关闭后恢复。
- 离开首页取消进行中的识题；请求序号阻止过期结果写入当前界面或触发跳转。已保存笔记继续通过 IndexedDB 恢复。
- 模型弹窗管理焦点、Tab 循环、Escape、背景滚动和可视窗口高度，适配键盘占用窗口的情况。
- 视频与供应商外链统一经过平台打开器；原生壳不会用网页地址替换应用文档。组件已经处理的点击不会再次被全局处理，避免打开两个窗口。
- 未知地址、无效讲题阶段提供返回拍题入口。内部片段弹窗在卸载时恢复页面滚动。

## 验收标准与证据

`frontend/tests/app-shell.spec.ts` 检查各阶段共享文档和外壳、零新增主文档请求、返回、记录恢复、裁剪状态、取消识题、弹窗及原生外链调用。已有回归覆盖完整讲题流程、320/360/390/430 宽度、桌面、长公式、导航预留空间、错误恢复和离线资产缓存。所有模型请求使用隔离数据，不消耗真实额度。

构建后通过 Chromium 和 WebKit 直接访问 `/history` 与未知地址，再刷新，均正常呈现应用；默认构建未产生管理工具页面的模块。H5 部署时必须配置 history 回退，例如 Nginx：

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

API 应独立配置代理位置，避免 API 错误被回退成 HTML。Vite 开发服务和 preview 自带路由回退，不能据此推断所有生产服务器都已正确配置。

本轮执行结果：Chromium 全量回归 48 通过、3 项环境或内部工具用例跳过；内部工具另行开启后 1 项通过。新增 7 项应用形态回归在 Chromium、WebKit 均通过，WebKit 其余所选回归 38 项通过、2 项跳过。TypeScript 检查和正式构建通过。

## 验证边界

本轮原生验证使用浏览器模拟 Tauri 标识、hash 路由与打开器调用，并非 Android/iOS 真机验收。系统返回键、边缘返回手势、真实软键盘、安全区、应用切后台及进程被回收后的表现需要在对应设备上验证。不能把“SPA 已通过”视为这些系统行为全部通过。

内部目录工具单独开启后执行回归；依赖私有管理员凭据与隔离 Go 服务的用例未提供环境时跳过。WebKit 本轮未执行依赖浏览器 URLPattern 的原生 HTTP 模拟专项；相关用例在 Chromium 中执行。

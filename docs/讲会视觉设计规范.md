# 讲会视觉设计规范

2026-10-04 更新。应用式学习工作台，手机版为主要入口；使用现有 Vue SPA 和业务接口。

## Logo

图形由对话框、理解后的勾、青柠色光点组成。对话框表示家长与孩子一起讲题；勾表示把知识点弄明白；光点表示“原来如此”的瞬间。标志为原创代码绘制的 SVG，不依赖外部图片或字体。

- [主标志](../frontend/src/assets/brand-mark.svg)：64 × 64 viewBox，适合缩放及导出。
- [网页图标](../frontend/public/favicon.svg)：与主标志同源。
- [复用组件](../frontend/src/components/BrandMark.vue)：用于侧栏、手机顶栏、登录及加载状态。

标志旁保留“讲会”文字。常用尺寸为手机顶栏 34px、桌面 40px、登录/加载 38–44px；四周留出至少约 6px 的空间。保留完整尾角与光点，不拉伸、不加外描边。

## 界面与排版

桌面采用固定侧栏、常驻顶栏和内容工作区；手机采用精简顶栏与两项底部导航。讲题过程中收起全局底部导航，使用当前步骤操作区，避免按钮互相遮挡。页面导航复用应用外壳，通过 Vue Router 切换内容。

首页分为两个单屏状态：无记录时展示拍题入口与“从看懂，到讲会”引导；有记录时展示拍新题入口与最近三条记录，省去引导。更多记录进入完整历史页查看；扫描插图使用本地 SVG 线条，讲稿、老师片段和结果页采用同一套卡片、数字进度和图标。圆角以 11–20px 为主，阴影只强调操作与弹窗。

字体使用系统无衬线中文字体，不加载外部字体服务。正文与讲稿通常为 16px，题目与提问适当放大；数学公式由 KaTeX 渲染，完整公式保持完整，超宽部分局部滚动。

支持安全区、键盘缩小视口和减少动画的系统偏好。交互焦点以蓝色外框表示，主要操作至少 44px 高。
